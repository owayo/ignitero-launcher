# AI利用枠とWebページのMarkdown取得

`ai`、`ai usage`、`利用枠`で利用枠一覧を開く。アカウント別の使用率と周期、リセット予定、
手動リセットを表示する。不明な使用率は0%として描かず、周期が不明な場合は短期枠・長期枠とする。
更新失敗時は前回の表示と時刻を残し、エラーを表示する。

利用枠は1アカウント1行の一覧にし、使用率とリセットまでの時間を横に揃えた。
初期サイズは760×440ptで、5アカウントと長い取得エラーを含むデータが縦スクロールなしで
収まることを、幅680pt・760ptで検証した。件数が多い場合や画面を縮めた場合はスクロールできる。
プラン名・手動リセットの期限・エラー全文は各行の詳細ボタン、アクセス許可の案内はヘルプで開く。

`md URL`でページを取得する。`md`のみならURLの入力画面を開き、取得後のMarkdownを編集・コピーできる。
HTTP/HTTPSと日本語URLに対応し、パス・クエリの大文字小文字を維持する。
本文が空のときと取得失敗時はコピーを無効にする。取得結果は2MiBを上限とする。
通常のブラウザのログイン状態は取得用Chromeへ引き継がない。

両画面とも検索欄のEnterとメニューから開ける。Esc、閉じるボタン、ランチャー切り替えで閉じる。
パネルはSafeHostingViewのコンテナに埋め込み、AppKitがサイズを管理する。
本文やURLをランチャーの選択履歴に記録しない。AI利用枠はai-usageの既存キャッシュを読み書きする。

## ネイティブ連携

ai-usageの参照は `f230ff18`、get-mdは `657c3f0d`。
[ai-usage #4](https://github.com/owayo/ai-usage/pull/4) と
[get-md #2](https://github.com/owayo/get-md/pull/2) でライブラリAPIを追加し、mainへスカッシュマージした。
設定・認証・キャッシュやHTMLの抽出・Markdown変換は既存の実装を再利用する。

Native/LauncherBridgeは両ツールとOCRを1つのRust静的ライブラリにまとめる。
複数のRustランタイムを静的リンクせず、SQLiteもシステム版へ揃える。
C ABIは要求JSON・ジョブ・結果JSONを受け渡し、schema_versionは1。文字列とハンドルは一度だけ解放する。
所有権、同時呼び出し、開始時のbusyステータスはCヘッダに記載した。

実行中のジョブは各ツール1つに制限する。Swift側は待機中にスケジューラへ処理を戻し、
閉じた要求や置き換えられた要求の結果を捨てる。UIの中止でai-usageの取得Futureを途中で破棄せず、
既存の認証更新とキャッシュ処理が戻ってから結果を捨てる。次の取得はその後に開始する。
get-mdはブラウザ操作の間と描画待機中に中止を確認する。同期ナビゲーションはタイムアウトまで
後始末が続く場合があり、OSの権限確認は利用者の操作を待つ。

## 検証

ai-usageの327テストとClippy、システムSQLiteでのビルド、get-mdの799テストとClippyが通過した。
get-mdの追加E2Eも実行し、ローカルHTTPページでJS描画・非表示要素・相対リンク・タイトル・404を確認した。
両PRのCIは成功している。Rust側のC ABIではJSON契約、busy、中止、文字列の一度だけの取得を検証した。

Swiftの全体テスト1,166件が通過した。ネイティブ連携ではChromeでのMarkdown取得とエラー伝搬に加え、
日本語OCR、明暗の多数行OCR、英単語間スペースの既存テストを実行した。
署名済みアプリから実際のAI利用枠の取得も確認した。アカウント情報や取得した本文はこの記録へ載せていない。

最低OSはmacOS 26のまま。実行確認はmacOS 27・Swift 6.4のApple Siliconで行っており、
macOS 26・Swift 6.2/6.3とIntel実機での起動は未確認。

GUIからの起動では、ChromeのCookieへのアクセスがmacOSのAppData保護で拒否された。
ターミナルからの自己診断は、起動元の権限で成功するため、この制限の検証になっていなかった。
フルディスクアクセスがONでも、古い署名に対する登録が残っている場合は現在のアプリを
登録し直して完全終了・再起動する必要がある。利用枠画面に設定への導線を追加し、
Info.plistにはアクセス目的を記載した。権限の変更は利用者の許可を得て行う。
Cookie探索が読み取り拒否と不存在を区別しない点は、
[ai-usage #5](https://github.com/owayo/ai-usage/issues/5) に記録した。
